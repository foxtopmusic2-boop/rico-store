# ريكو ستور - Rico Store 🎬
> المنصة المتكاملة لمشاهدة الأفلام والمسلسلات العالمية بجودة فائقة (4K / HD) بديلة ومطابقة لتجربة **flixer.gd**.

---

## 🌟 مميزات منصة ريكو ستور (Rico Store)

1. **تصميم سينمائي فائق الدقة (Flixer Dark UI):**
   - واجهة مظلمة سينمائية مستوحاة من أفضل منصات البث العالمية (Flixer / Netflix / Apple TV+).
   - تأثيرات الزجاج المصقول (Glassmorphism) وتوهجات حمراء نيونية مميزة بشعار "ريكو ستور".
   - تجاوب كامل 100% مع شاشات الحواسيب، الأجهزة اللوحية، والهواتف الذكية مع شريط تحكم سفلي (Mobile Bottom Dock).

2. **سلايدر العرض المميز (Hero Featured Slider):**
   - تقليب تلقائي للأعمال الأكثر طلباً مع خلفيات بدقة 4K.
   - معلومات تفصيلية عن سنة الإنتاج، التقييم، الجودة، والتصنيفات.
   - زر تشغيل فوري، نافذة منبثقة لمشاهدة الإعلان الرسمي (Trailer) عبر يوتيوب، وزر المفضلة.

3. **مشغل فيديو متعدد الخوادم (Multi-Server Streaming Engine):**
   - يدعم التبديل اللحظي بين 5 خوادم بث سريعة:
     - **VidSrc Pro VIP (4K Ultra)**
     - **VidSrc CC (1080p HD)**
     - **AutoEmbed (سيرفر عالمي متعدد اللغات)**
     - **SuperEmbed (خادم خفيف وسريع)**
     - **مشغل ريكو ستور المدمج (Native HTML5 Demo Player)**
   - دعم كامل للأفلام والمسلسلات مع محدد الحلقات والمواسم (Seasons & Episodes Selector).
   - وضع السينما (Cinema Mode / تعتيم كامل للشاشة).
   - وضع ملء الشاشة بزر واحد وميزة مشاركة العمل.

4. **تكامل البيانات الحية (Live TMDB API Integration):**
   - جلب مباشر لآلاف الأفلام والمسلسلات الحقيقية مع ملصقات، خلفيات، أسماء الممثلين وصورهم، التقييمات، والتوصيات.
   - قاعدة بيانات مدمجة غنية (Mock Cache) لضمان استمرار عمل الموقع بأعلى سرعة حتى عند انقطاع الإنترنت أو وجود بطء.

5. **نظام البحث الفوري (Live Instant Search):**
   - بحث لحظي عند الكتابة (Autocomplete) مع شاشة منبثقة تعرض الصور والتقييم وسنة الإصدار ونوع العمل.

6. **لوحة استكشاف وتصفية شاملة (Explore & Filter):**
   - فلترة حسب: نوع العمل (فيلم أو مسلسل)، التصنيف (أكشن، رعب، خيال علمي، كوميديا، دراما...)، سنة الإصدار، وطريقة الترتيب (الأعلى تقييماً أو الأكثر شعبية).

7. **قائمة مفضلاتي (Watchlist) وسجل المشاهدة (Watch History):**
   - حفظ تلقائي للمفضلة وسجل المشاهدة في الذاكرة المحلية للمتصفح (LocalStorage) بدون الحاجة لتسجيل دخول.
   - شارة رقمية في شريط التنقل توضح عدد الأعمال المحفوظة.

8. **دعم كامل للغتين (العربية والإنجليزية):**
   - تبديل فوري بين العربية (RTL) والإنجليزية (LTR) بضغطة زر واحدة.

## 🚀 كيفية تشغيل المشروع

### الطريقة الأولى: التشغيل المباشر
فقط افتح ملف `index.html` في أي متصفح (Chrome, Edge, Firefox, Safari) بالنقر المزدوج عليه.

### الطريقة الثانية: عبر خادم محلي مدمج
افتح موجه الأوامر في مجلد المشروع ونفّذ:
```bash
python server.py
```
ثم افتح الرابط:
👉 **`http://localhost:8080`**
